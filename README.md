# EasyBuild

Plataforma web para criação, compartilhamento e organização de builds, runas, estratégias e guias para jogos.

## Objetivo

O EasyBuild foi criado para permitir que jogadores encontrem e compartilhem builds de forma simples, rápida e organizada.

## Funcionalidades

- Sistema de builds
- Organização por categorias
- Interface moderna
- Estrutura escalável
- Frontend em Next.js
- Design responsivo

## Tecnologias

- Next.js
- TypeScript
- React
- CSS
- Node.js

## Como executar

Clone o projeto:

```bash
git clone https://github.com/loamysilva/easybuild.git
```

Entre na pasta:

```bash
cd easybuild
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```

Acesse:

```bash
http://localhost:3000
```
